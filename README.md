# minesweeper-2026

Навчальний репозиторій курсу «Web-технології та Web-дизайн» для виконання практичних робіт №1 та №2 (гра «Сапер» на HTML5, CSS3 та Vanilla JavaScript ES6+).

## Структура робіт
- `KostrovMykyta/` — персональна директорія студента Кострова Микити Борисовича (група КС-32):
  - **ПР №1** (гілка `lab1/kostrov-mykyta-minesweeper-ui-layout`): семантична розмітка (`index.html`) та стилізація інтерфейсу і всіх станів клітинок (`styles.css`).
  - **ПР №2** (гілка `lab2/kostrov-mykyta-js-dom-minesweeper`): ігровий шар даних (`gameState`), генерація мін з безпечним першим кліком, рекурсивне відкриття порожніх клітинок (Flood-Fill), таймер та делегування подій DOM (`script.js`).
